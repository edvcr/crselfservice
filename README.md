# CoinsRaid Help Widget — Demo

Live demo of the CoinsRaid Help Center widget (Device Lab with Desktop/Tablet/Mobile views).

- `index.html` — Device Lab (default page)
- `share.html` — bare widget stage, no lab chrome

Both files are self-contained builds (widget + article snapshot inlined).
To update: run `node build_share.js` in the source folder, copy
`public/index.html` and `public/share.html` here, commit and push.
